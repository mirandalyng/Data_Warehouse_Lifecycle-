# Setup Snowflake

## Connect to VSC

- Click on profile
- Account details
- copy url
- VSC - install extenstion Snowflake
- Sidepanel in VSC has Snowflake
- Put url in there
- sign in (fill in username)
- Click login (link opens in browser and login )
- Go back to vsc

## Change language to snowflake

- shift + command + p
- change language mode
- choose snowflake

## Query History

- in web snowflake
