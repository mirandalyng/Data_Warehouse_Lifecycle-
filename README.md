# Data Warehouse Lifecycle (Data Integration Architecture)

Repository for the course **Data Warehouse Lifecycle (Data Integration Architecture)**, part of the **Data Engineer 400 YHP** program (course code YH02012-2023-3).

|                     |                                               |
| ------------------- | --------------------------------------------- |
| **Credits**         | 35 HVE credit points                          |
| **Elective course** | No                                            |
| **Language**        | Swedish (course literature may be in English) |
| **Prerequisites**   | None                                          |

## About the course

The course provides knowledge and skills in data warehouse architecture and its lifecycle — from requirements gathering and capacity planning to ETL/ELT development, data integration, and presentation through BI tools.

## Course modules

- Requirements gathering
- Sizing and capacity planning
- Data modeling
- ETL/ELT, design and development
- Modern Data Stack
- Selecting BI/reporting tools
- Maintenance
- Testing and development

## Assessment

| Outcomes           | Format             | Grading scale                   |
| ------------------ | ------------------ | ------------------------------- |
| KUN15, KUN16, KOM9 | Written assignment | Fail/Pass/Pass with Distinction |
| F17, F18           | Project work       | Fail/Pass/Pass with Distinction |

**Requirements for Pass with Distinction (project work):** active participation in group work, a meaningful individual contribution to designing, developing, and testing an ETL/ELT pipeline, clear understanding of how to extend or adjust an existing data warehouse, a professional and clear presentation, and the ability to answer follow-up questions with technical precision.

After the regular assessment occasion, students are entitled to two additional resit or supplementary opportunities.
